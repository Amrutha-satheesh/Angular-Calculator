# Angular Calculator

A functional web-based calculator built using Angular. This project focuses on handling user input logic and dynamic UI updates.

## 🚀 Features
* **Basic Math:** Supports addition, subtraction, multiplication, and division.
* **Advanced Operations:** Includes Square Root (√) calculation.
* **Correction Tools:** * `C` button to clear the entire display.
* `←` (Backspace) to delete the last digit entered.


## 💻 Tech Stack
* **Framework:** Angular 
* **Language:** TypeScript
* **Structure and Styling:** HTML & CSS

## 🛠️ How to Use
1. Run `ng serve` to start the local development server.
